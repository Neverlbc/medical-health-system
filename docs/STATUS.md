## 近期已完成

### 1. 本地数据库联调
- `medical-admin/src/main/resources/application.yml` 默认数据库连接指向 `localhost:3306/medical_health`。
- 默认数据库账号保持 `root`，默认密码已改为空安全占位；本地测试通过 `.env` 或环境变量 `DB_PASSWORD` 覆盖。
- 远程 MySQL `47.85.48.198:3306` 连接超时不再作为开发阻塞点。

### 2. 首页云小医 Agent
- 新增首页浮窗组件 `YunXiaoYiAgent`，命名为“云小医”。
- 已接入默认布局，在患者首页、医生首页展示入口。
- 支持按角色生成不同提醒：
  - 患者：健康异常、用药/治疗方案、检查复查、预约就诊、档案补充提醒。
  - 医生：今日接诊、待处理预约、重点患者风险提醒。
  - 管理员：运营概览、排班风险、健康异常数据提醒。
- 健康提醒已从首页固定占位改为进入云小医对话中呈现，符合“提醒放到机器人对话里”的产品方向。

### 3. AI 问诊体验
- AI 回复尾注从 Markdown 分割线和强调符号改为普通提示文案，减少特殊符号干扰。
- 优化 AI 回复渲染：支持标题、加粗、列表的基础格式化，同时过滤多余分割线和重复免责声明。
- 清空对话按钮逻辑已补齐，清理后保留当前系统提醒并给出用户反馈。
- 输入区高度和消息加载状态已优化，避免下半区占用过大。

### 4. 视觉体系升级
- 全局主题从蓝白“AI 感”调整为暖棕、米白、鼠尾草绿、柔和玫瑰色的医疗服务风格。
- `DefaultLayout`、登录页、患者首页、医生首页、预约页、AI 问诊页、档案列表页已完成主要配色替换。
- Element Plus 主色、按钮、输入框、表格、卡片、滚动条已做全局暖色覆盖。
- 页面整体方向：减少冷蓝、弱化科技模板感，提升温馨感、医疗可信感和高级感。

### 5. 健康档案摘要完善
- 病历列表不再只依赖 `patient_record` 表的摘要字段。
- 列表摘要已改为多来源兜底：
  - 过敏史：档案摘要 → 结构化 `patient_allergy` 聚合 → `patient_info.allergies`
  - 既往史：档案摘要 → 结构化 `patient_history(PAST)` 聚合 → `patient_info.medical_history` → 近诊断记录
  - 家族史：档案摘要 → 结构化 `patient_history(FAMILY)` 聚合 → `patient_info.family_history`
- 搜索范围已覆盖患者姓名、备注、过敏史、家族史、既往史及结构化聚合摘要。
- 前端列表新增“家族史摘要”列，并用暖色摘要标签替代“未建立”占位。
- 没有档案 ID 的患者禁用附件入口，避免无效点击。

### 6. 构建与工程配置
- `vite.config.ts` 已加入 Sass `legacy-js-api` 降噪配置，减少 Vite HMR 阶段重复警告。
- 路由鉴权已兼容 `ROLE_` 前缀，避免后端角色字段格式差异导致误跳转。
- `record.ts` 补充列表页实际使用的 `patientName`、`gender`、`age` 类型字段。
